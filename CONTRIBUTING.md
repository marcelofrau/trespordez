# Contributing

1. Read `AGENTS.md` and `docs/content-model.md`.
2. Create or edit Markdown and assets.
3. Run `node scripts/validate-site.mjs` and `bundle exec jekyll build`.
4. Commit with conventional format, for example `content: add review of Example`.
5. Push only after content owner approves. `main` updates QA and, after launch, production.

Never change an existing post permalink without a documented redirect.
