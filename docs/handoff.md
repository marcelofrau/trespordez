## Architecture

- Jekyll 4 static site.
- GitHub Actions validates `main`. Cloudflare Pages builds and deploys `main` to `trespordez.pages.dev`.
- Giscus is active using GitHub Discussions. Build reads `GISCUS_REPO_ID` and `GISCUS_CATEGORY_ID` GitHub Variables through `scripts/prepare-giscus.mjs`; generated `_data/giscus.yml` is ignored.
- Comments map to `post-<slug>`, so QA and production share a Discussion.

## Visual System

- Heading font: Chakra Petch. Body font: Alegreya Sans.
- Card language: dark outlines, rounded corners, hard shadows, yellow accent, blue-gray page canvas.
- Header uses local `assets/images/site/header-backdrop-v2-blur.jpg`, fixed on desktop; logo and menu stay above it.
- CSS cache busting uses site build timestamp in `head.html`.
- Use `relative_url` for local HTML URLs. Markdown image HTML must use Liquid `relative_url` under QA.
- Desktop article paragraphs are justified. Mobile text remains left-aligned.

## Content Structures

- Posts: `_posts/YYYY-MM-DD-slug.md`.
- Existing rich WordPress pages: `_pages/wordpress/`.
- Initial emulator catalogs: `_pages/platforms/`; generated by `scripts/generate-platform-drafts.mjs`. Do not frame them as personal recommendations.
- System index: `_pages/emuladores.md` with `_data/platforms.yml` cards.
- Ports hub: `_pages/ports.md`; Video Game Esoterica entries: `_pages/ports/`, generated by `scripts/generate-vge-port-pages.mjs`.
- Tags: `_pages/tag/`; regenerate after taxonomy edits with `node scripts/generate-tag-pages.mjs`.
- Retrobright: `_pages/retrobright.md`, route `/category/consoles/retrobright/`. It contains guide/reference content plus placeholder for owner photos/results.
- Software catalog: `_pages/softwares.md`.

## Images And Assets

- Post images: `assets/images/posts/<slug>/`.
- Page images: `assets/images/pages/<slug>/`.
- Local raw sources: `_library/`, ignored and never committed.
- Approved ReffPixels subset: `assets/images/ui/review/`; attribution in `docs/asset-credits.md`.
- New site backdrop source was supplied by owner in `_library`; optimized copy is committed in `assets/images/site/`.
- Galleries: `.post-gallery` + PhotoSwipe. Do not place long screenshot sequences as full-width images.
